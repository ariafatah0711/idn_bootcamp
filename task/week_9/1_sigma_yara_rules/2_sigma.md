## flow sigma
```bash
Log mentah (raw logs dari Windows/Linux) 
     ↓
  Dikirim ke SIEM (Splunk, Elastic, dll)
     ↓
 SIEM parsing dan indexing log
     ↓
 Sigma Rule (format .yml) dipakai → dikonversi ke query SIEM pakai sigma-cli
     ↓
 Query dijalankan di SIEM → menghasilkan alert atau hasil pencarian
```

## setup
### windows
- Install Python & Git
- Install Sigmac (Sigma converter):

```bash
git clone https://github.com/SigmaHQ/sigma.git
pip3 install sigma-cli
```

### linux
```bash
apt update
apt install git python3-pip -y

apt install python3-full -y # if err externally-managed-environment
# pip3 install sigma-cli
pip3 install sigma-cli --break-system-packages
```

or from source

```bash
git clone https://github.com/SigmaHQ/sigma-cli.git
cd sigma-cli
apt install python3-poetry
poetry install && poetry shell
sigma version
```


## command
```bash
# 1
sigma plugin list
sigma plugin install splunk
# 2
sigma list pipelines splunk
# 3 (jangan lupa buat file rulesnya)
## Create a test repository to store your detections-as-code
mkdir sigma_test_repo && cd sigma_test_repo
mkdir ./rules
# Create a new Sigma rule
sigma convert win_malware_lab01_01.yml -t splunk --pipeline splunk_sysmon_acceleration
sigma convert win_malware_lab01_01.yml -t splunk --without-pipeline
# 4 (opsional untuk save splunk)
sigma convert win_malware_lab01_01.yml -t splunk --pipeline splunk_sysmon_acceleration > output.spl
# 5 scan
sigma scan /var/log/syslog --rules ./win_malware_lab01_01.yml
---

# convert
sigma convert path/to/rule.yml --target splunk
sigma convert rules/windows/builtin/win_susp_powershell_download.yml --target splunk

# scan
sigma scan path/to/logfile.log --rules path/to/rules/
sigma scan /var/log/syslog --rules ./rules/

# list
sigma list targets
sigma list rules ./rules/

# test rules
sigma test path/to/rule.yml

# Build rule index
sigma index update ./rules/

# Filter rule berdasarkan kriteria
sigma filter --tags "attack.persistence"

# Build pipeline untuk custom converter
sigma build pipeline --target splunk
```

```bash
# konversi 1 rule jadi format Elastic Query
sigma convert rules/linux/process_creation/lnx_susp_su_activity.yml --target es-qs

# scan log lokal pakai rule yang kamu punya
sigma scan /var/log/auth.log --rules ./rules/
```

## rules
* Dapatkan sample malware (contoh: .exe, .dll, .bin)
* Jalankan `strings namafile` untuk melihat isi string mencurigakan
* (Opsional) Upload ke VirusTotal untuk cek SHA256 dan behavior
* Salin hasil `strings` ke ChatGPT untuk dibuatkan SIGMA rule
* Simpan dan tes dengan `yara rule.yar namafile`

### 1
```bash
sigma plugin install splunk

mkdir ./rules
cat << "EOF" > ./rules/win_malware_lab01_01.yml
title: Suspicious Lab01-01 Malware Activity
id: 6c0d0fd0-b91e-4c91-900a-f13faaa0ff01
description: Detects suspicious behavior from malware sample Lab01-01.dll based on known strings
status: experimental
author: Generated by ChatGPT
date: 2025-07-24
logsource:
  product: windows
  category: process_creation
detection:
  selection:
    CommandLine|contains:
      - "CreateProcessA"
      - "CreateMutexA"
      - "OpenMutexA"
      - "CloseHandle"
      - "exec"
      - "sleep"
      - "hello"
      - "127.26.152.13"
    ImageLoaded|contains:
      - "WS2_32.dll"
  condition: selection
fields:
  - CommandLine
  - Image
  - ParentImage
falsepositives:
  - Custom tools or benign programs using similar API calls
level: high
tags:
  - attack.execution
  - attack.persistence
  - malware.lab
EOF

sigma convert \
    --target splunk \
    --pipeline splunk_windows \
    ./rules

---

sigma list pipelines splunk

# liat splunknya ada apa aj trus copy di pipeline
sigma convert win_malware_lab01_01.yml -t splunk --pipeline splunk_sysmon_acceleration
# sigma convert win_malware_lab01_01.yml -t splunk --without-pipeline # opsional tapi kurang

sigma scan /var/log/syslog --rules ./rules/
```
