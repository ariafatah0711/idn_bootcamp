## setup
### windows
- Install Python & Git
- Install Sigmac (Sigma converter):

```bash
git clone https://github.com/SigmaHQ/sigma.git
cd sigma/tools
pip install -r requirements.txt
```

### linux
```bash
apt update
apt install git python3-pip -y
git clone https://github.com/SigmaHQ/sigma.git
cd sigma/tools
pip install -r requirements.txt
```
