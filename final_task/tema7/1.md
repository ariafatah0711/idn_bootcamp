# Project: IaC & Container Security Audit — Blueprint

**Tujuan:** Otomatiskan pemeriksaan keamanan untuk Dockerfile, Kubernetes manifests (YAML), dan Terraform. Hasilnya: laporan terpusat (Markdown/HTML) yang mencantumkan temuan, severity, rekomendasi dan mapping ke benchmark.

**Ringkasan Workflow:**

1. Clone atau taruh repositori target di `workspace/`.
2. Jalankan scanner: Trivy (image/fs/config), Checkov (Terraform), Dockle (Dockerfile), kube-score (K8s).
3. Kumpulkan output JSON dari tiap tool.
4. Gabungkan ke dalam laporan HTML + Markdown.

---

## Prasyarat

* Linux / macOS (bash)
* Python 3.8+
* Tool yang direkomendasikan (install via package manager / binaries):

  * `trivy` ([https://github.com/aquasecurity/trivy](https://github.com/aquasecurity/trivy))
  * `checkov` (pip install checkov)
  * `dockle` ([https://github.com/goodwithtech/dockle](https://github.com/goodwithtech/dockle))
  * `kube-score` ([https://github.com/zegl/kube-score](https://github.com/zegl/kube-score))
  * optional: `snyk` CLI jika ingin integrasi

> Catatan: script akan mencoba mendeteksi ketersediaan tiap tool dan melaporkan jika tidak ditemukan.

## scripts/scan\_all.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

WORKDIR="$(dirname "$0")/.."
WORKSPACE="$WORKDIR/workspace"
OUTDIR="$WORKDIR/outputs"
mkdir -p "$OUTDIR"

# helper
run_cmd(){
  echo "\n>> $*" >&2
  "$@"
}

# 1) Trivy (filesystem IaC & container image)
if command -v trivy >/dev/null 2>&1; then
  echo "Running trivy filesystem scan..."
  trivy fs --format json --output "$OUTDIR/trivy_fs.json" "$WORKSPACE" || true
  echo "Running trivy config scan (IaC)..."
  trivy config --format json --output "$OUTDIR/trivy_config.json" "$WORKSPACE" || true
else
  echo "trivy not found, skipping trivy (install from https://github.com/aquasecurity/trivy)"
fi

# 2) Checkov for Terraform
if command -v checkov >/dev/null 2>&1; then
  echo "Running checkov..."
  checkov -d "$WORKSPACE" --output json > "$OUTDIR/checkov.json" || true
else
  echo "checkov not found (pip install checkov)"
fi

# 3) Dockle - scan Dockerfiles (works against images; for Dockerfile we attempt to build minimal image tag if Docker available)
if command -v dockle >/dev/null 2>&1; then
  echo "Running dockle on Dockerfiles found..."
  find "$WORKSPACE" -type f -name Dockerfile | while read -r df; do
    # use dockle's filesystem mode (dockle supports scanning image or checking Dockerfile via build recommended)
    RELPATH="${df#$WORKSPACE/}"
    echo " - Dockerfile: $RELPATH"
    # attempt to build image name temp/build-<hash> if docker exists
    if command -v docker >/dev/null 2>&1; then
      TAG="temp-build-$(echo "$RELPATH" | tr '/ ' '_' | tr -c '[:alnum:]_' '-')"
      docker build -t "$TAG" -f "$df" "$(dirname "$df")" || true
      dockle --format json --output "$OUTDIR/dockle_$(basename $(dirname "$df")).json" "$TAG" || true
      docker image rm "$TAG" >/dev/null 2>&1 || true
    else
      echo "  docker cli not available; skipping build for $df"
    fi
  done
else
  echo "dockle not found, skipping"
fi

# 4) kube-score for kubernetes YAML
if command -v kube-score >/dev/null 2>&1; then
  echo "Running kube-score on YAML manifests..."
  find "$WORKSPACE" -type f -name "*.yaml" -o -name "*.yml" | while read -r y; do
    BASE="$(basename "$y")"
    kube-score score "$y" --output-file "$OUTDIR/kubescore_$BASE.txt" || true
  done
else
  echo "kube-score not found, skipping"
fi

# 5) Summarize
python3 "$WORKDIR/scripts/reporter.py" --outdir "$OUTDIR" || true

echo "All done. Outputs in: $OUTDIR"
```

## scripts/reporter.py

```python
#!/usr/bin/env python3
"""
Simple aggregator: baca JSON dari trivy/checkov/dockle, parse temuan dan buat report Markdown + HTML
"""
import json
import sys
from pathlib import Path
import argparse

TEMPLATE = """
<!doctype html>
<html>
<head><meta charset="utf-8"><title>IaC & Container Audit Report</title></head>
<body>
<h1>Audit Report</h1>
<p>Generated: {generated}</p>
{body}
</body></html>
"""

from datetime import datetime

def load_json(path: Path):
    try:
        return json.loads(path.read_text())
    except Exception:
        return None


def summarize_trivy(fs_json):
    if not fs_json:
        return ''
    rows = []
    # trivy fs output may have 'Results' list
    for r in fs_json.get('Results', []):
        target = r.get('Target')
        vulns = r.get('Vulnerabilities') or []
        for v in vulns:
            rows.append((target, v.get('VulnerabilityID'), v.get('PkgName'), v.get('Severity'), v.get('Title')))
    if not rows:
        return '<h2>Trivy</h2><p>No issues found.</p>'
    s = '<h2>Trivy findings</h2><ul>'
    for t, vid, pkg, sev, title in rows:
        s += f'<li><b>{sev}</b> {vid} in {pkg} (target: {t}) — {title}</li>'
    s += '</ul>'
    return s


def summarize_checkov(checkov_json):
    if not checkov_json:
        return ''
    s = '<h2>Checkov findings</h2><ul>'
    for r in checkov_json.get('results', {}).get('failed_checks', []):
        s += f"<li><b>{r.get('check_id')}</b> {r.get('check_name')} - {r.get('file_path')} (severity: {r.get('severity')})</li>"
    s += '</ul>'
    return s


def summarize_dockle(paths):
    s = ''
    for p in paths:
        j = load_json(Path(p))
        if not j:
            continue
        s += f'<h2>Dockle ({Path(p).name})</h2><ul>'
        for i in j.get('warnings', []) + j.get('errors', []):
            s += f'<li>{i.get("code")}: {i.get("message")}</li>'
        s += '</ul>'
    return s


def summarize_kubescore(txtpaths):
    s = ''
    for p in txtpaths:
        try:
            content = Path(p).read_text()
        except Exception:
            continue
        s += f'<h2>kube-score: {Path(p).name}</h2><pre>{content[:8000]}</pre>'
    return s


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--outdir', default='outputs')
    args = parser.parse_args()
    out = Path(args.outdir)
    trivy_fs = load_json(out / 'trivy_fs.json')
    trivy_config = load_json(out / 'trivy_config.json')
    checkov = load_json(out / 'checkov.json')
    dockle_files = list(out.glob('dockle_*.json'))
    kube_score_txts = list(out.glob('kubescore_*.txt'))

    body = ''
    body += summarize_trivy(trivy_fs)
    body += summarize_trivy(trivy_config)
    body += summarize_checkov(checkov)
    body += summarize_dockle(dockle_files)
    body += summarize_kubescore(kube_score_txts)

    html = TEMPLATE.format(generated=datetime.utcnow().isoformat() + 'Z', body=body)
    md = '# Audit Summary\n\nGenerated: {}\n\n'.format(datetime.utcnow().isoformat() + 'Z')
    md += 'See outputs directory for raw JSON from each tool.\n'

    out.mkdir(parents=True, exist_ok=True)
    (out / 'report.html').write_text(html)
    (out / 'report.md').write_text(md)
    print('Report generated:', out / 'report.html')

if __name__ == '__main__':
    main()
```

## Cara pakai (quickstart)

1. Clone project ke mesin lab.
2. Taruh target repo-folder di `workspace/` (misal `workspace/sample-app`).
3. Pastikan `trivy`, `checkov`, `dockle`, `kube-score` terinstall (atau beberapa di antaranya jika ingin iterasi bertahap).
4. Jalankan:

```bash
chmod +x scripts/scan_all.sh
./scripts/scan_all.sh
```

5. Buka `outputs/report.html` untuk membaca hasil agregasi.
