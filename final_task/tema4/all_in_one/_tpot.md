# tpotce
- [tpotce](https://github.com/telekom-security/tpotce)

## setup
```bash
git clone https://github.com/telekom-security/tpotce
cd tpotce
```
custom honeypot yang ingin di run
```bash
nano docker compose.yml
docker compose up -d
```
