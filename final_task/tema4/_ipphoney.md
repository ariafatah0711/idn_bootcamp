# ipphoney
- [https://gitlab.com/bontchev/ipphoney](https://gitlab.com/bontchev/ipphoney)

## setup
### setup python (blm nyoba)
```bash
git clone https://gitlab.com/bontchev/ipphoney
cd ipphoney
pip3 install -r requirements.txt
python3 ipphoney.py
```

### setup docker (nyoba build docker image tapi loadingnya lama)
```bash
docker build -t ipphoney .
docker run -it --name ipphoney --net=host ipphoney
```
